Use CONTROLLER_TRANSMITTER.ino to add to your existing code!

You will see the BOT_RECEIVER code, but you do not need it as it will already be on the Zumo Bot. 

Use the Menu for any additional inputs you'd like to add.
This menu will be on the Zumo, so all you will need to do is send the letter of what you'd like to use.


Your controller will need to have a space to connect to the Bluetooth Module either via jumper wires (female) or breadboard. 
You will need: 5v - GND - Digital Pin 3 - Digital Pin 2

Before testing with the bots, comment out any println for the Arduino IDE Serial Monitor!!!
